Shadow Client 0.2.0 for Windows 10 and 11 (64-bit). If you have 0.1.0, run the new installer over it; your profiles, worlds and settings stay. From now on the launcher tells you when a new version is out.

**Download:** `Shadow-Client-Setup.exe` is the normal installer. `Shadow-Client.msi` is for managed PCs, and `Shadow-Client-Portable.zip` runs from a folder without installing.

Windows may say "Windows protected your PC" because the installer isn't code-signed yet. Click **More info**, then **Run anyway**.

### New in 0.2.0
- **Servers page**: live status for Java and Bedrock servers (players, ping, version, MOTD) and a **Join** button that starts the game straight into the server.
- **Screenshot gallery** for each profile.
- **Crash helper**: when Minecraft crashes, the Home page names the likely cause (a broken mod, out of memory, the graphics driver…).
- **Update notices** in the launcher.
- **Bedrock worlds**: one-click backups as .mcworld files; restoring imports a backup as a new copy.
- **Mod menu 1.4 (300+ modules)**: waypoints with death markers, Auto Text hotkeys, kills and K/D, hit and kill sounds, 12 PvP alerts, 15 more item counters, Compact Chat, smaller held items, third person back only, hide offhand item, motion blur strength, and about 30 more option cards.
